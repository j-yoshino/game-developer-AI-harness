# Contract: 相談役の返答

相談役は、日本語で、次の形で返す。ファイルは書き換えない。決めて進めない。

```markdown
## 解釈案

### 案 1(推奨)
<内容。依頼をどう具体的にしたか>
含む補った点: A-1, A-2

### 案 2
<内容>
含む補った点: A-1, A-3

## 補った点

### A-1
- 見方: <番号> <名前>
- 内容: <何を補ったか>
- 根拠: <出どころの種類> / 強さ: <強|中|弱> / 出典: <任天堂の記事のときだけ。記事 NNN「題名」URL>
- 覆したときの影響: <何が変わり、どこまで戻るか>

## ユーザーに聞くこと

### 質問 1: <題>
- 選択肢 a: <内容>。選ぶと: <何が変わるか>
- 選択肢 b: <内容>。選ぶと: <何が変わるか>

## 相談役が根拠にできなかったこと

<根拠が薄い見方、ジャンルや規模が資料の例と違う点、資料の原則どうしが食い違う点。なければ「なし」>
```

## 規則

- 補った点の「根拠」の出どころの種類は、`任天堂の記事` / `二次資料の複合結果` / `出典なし(一般論)` のいずれか。
- `二次資料の複合結果` のとき、個別のソースを書かない。
- 断定的な数値や「必ず」の言い方は、そのまま使わず、条件つきで書く。
- 原則どうしが食い違うときは、両方を書き、依頼の条件で選ぶ。
- ジャンルや規模が、資料の例(対戦アクション、大作、大規模なチーム)と違うときは、狙いから読み替えたことを書く。
- 「状態」(合意・変更・却下)は、相談役が書かない。
