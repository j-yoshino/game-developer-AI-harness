# Contract: 相談役への委任メッセージ

相談役は、会話の履歴を見られない。メインは、次の節を、この順で、委任メッセージに書く。

| 節 | 内容 | 規則 |
|---|---|---|
| 1. ユーザーの原文 | 依頼と、聞き取りでのユーザーの発言 | 要約せず、そのまま貼る |
| 2. メインの理解 | 聞き取りで分かったこと、依頼の層(軽作業・本件) | 原文と区別する。結論やヒントを書かない(「これが良い」など) |
| 3. これまでの補った点 | 再び呼ぶときだけ。却下・変更された補った点と、ユーザーの理由、ユーザーが指定した方向 | 指定された方向は、原文のまま。初回は「なし」 |
| 4. 求めること | 「解釈案と、補った点を、返してください」 | 固定の一文 |

## 守ること

- 相談役の判定の方向を、ほのめかさない。
- 全案が却下されたときは、節 3 に、却下された案と理由を入れて、再び呼ぶ。
