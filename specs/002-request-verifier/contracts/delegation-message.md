# Contract: 確かめる者への委任メッセージ

メインが、確かめる者(`window-verifier`)を呼ぶときに書く、委任メッセージの形式。サブエージェントは、会話の履歴を見られないため、必要なものを、すべて、メッセージに貼る(research.md R4)。

## 呼び出し

`Agent` ツールで、`subagent_type` に `window-verifier` を指定する。

## 形式

```text
## ユーザーの原文
<ユーザーの言葉を、そのまま貼る>

## 依頼票(本件)/ 依頼(軽作業)
<本件: spec の依頼票の5欄をそのまま。
 軽作業: 納品書の「依頼」欄に書いた「こう理解した」と「やらないこと」を、全文>

## 納品書の本文
<docs/納品書/ の該当ファイルの全文。「確かめる者の報告」の節は、まだない>

## 変更ファイルの一覧
<git diff --name-only と、git ls-files --others --exclude-standard の結果>

## 依頼の層
本件 / 軽作業

## 検査の回数
1回目 / 2回目 / 3回目
```

## 規則

| 規則 | 内容 |
|---|---|
| 原文 | 要約しない。ユーザーの言葉のまま貼る |
| 納品書 | 全文を貼る。抜粋にしない(抜けの検査のため) |
| 変更ファイルの一覧 | メインが作る。確かめる者は、自分でも `git` で取り直し、突き合わせる |
| 結論を書かない | 「問題ない」「検査してほしい箇所はここ」のような、メインの判断を、メッセージに書かない(検査役の判断を、誘導しないため) |
| 差し戻しの2回目以降 | 前回の報告と、直した内容を、納品書の更新で示す。前回の判定を、メッセージに書かない |
