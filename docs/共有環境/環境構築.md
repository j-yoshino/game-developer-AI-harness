# 環境構築: Codex・Antigravity に superpowers を入れる

作成日: 2026-11-16。仕様: `specs/005-cross-tool-flow-gaps/`。

実装フローの入口は `brainstorming`(superpowers のスキル)。Claude Code は `settings.local.json` で superpowers を有効にしている。Codex と Antigravity には、次の手順で、プラグインとして入れる(スキルのコピーではない)。

## Codex アプリ(ChatGPT デスクトップアプリの Codex)

superpowers は、公式の一覧には出ない(2026-11-16 に、ユーザーが確認)。代わりに、このリポジトリのローカルのマーケットプレイスから入れる。操作は、ユーザーが行う。

このリポジトリの `.agents/plugins/marketplace.json` が、リポジトリ単位のマーケットプレイス(`game-developer-ai-harness-local`)で、`vendor/superpowers`(`.codex-plugin/plugin.json` を持つ)を指す。公式の説明: リポジトリ単位の置き場は `$REPO_ROOT/.agents/plugins/marketplace.json`、`source.path` は `./` で始め、マーケットプレイスのルートの中に置く(https://developers.openai.com/codex/plugins/build.md)。

1. Codex アプリで、このフォルダをプロジェクトとして開く(信頼を求められたら、信頼する)。
2. アプリを再起動する(公式の手動設定の手順に、再起動の記載がある)。
3. アプリの「Plugins Directory」(サイドバーの Plugins)を開き、マーケットプレイスの選択で「Game Developer AI Harness (local)」を選ぶ。
4. superpowers のプラスボタンを押して導入し、新しい会話を始める。
5. 確かめる: 新しい会話で「使えるスキルを一覧して」と聞き、`brainstorming` などが出ること。

- CLI を使う場合は、`codex plugin marketplace add ./`(リポジトリのルートで)でも追加できる(公式のコマンド)。一覧は `codex plugin marketplace list`。
- 公式の記載: 信頼したプロジェクトの `.codex/config.toml` に `[plugins."superpowers@game-developer-ai-harness-local"]` と `enabled = true` を書くと、プロジェクトごとに有効にできる。今回は、書いていない(アプリの操作で入れる)。

## Antigravity IDE

プロジェクト単位で入れる(そのプロジェクトでだけ有効。公式: https://antigravity.google/docs/plugins)。

1. リポジトリのルートで、次を実行する(`vendor/superpowers` から、`.agents/plugins/superpowers/` へコピーする)。

   ```bash
   python scripts/setup-antigravity-plugins.py --dry-run   # 置く先と中身を確かめる(何も書かない)
   python scripts/setup-antigravity-plugins.py             # 置く
   ```

2. Antigravity IDE で、このフォルダを開き(または開き直し)、エージェントのサイドパネルの「Customizations」のドロップダウンで、superpowers のスキルが読み込まれていることを確かめる。
3. `vendor/superpowers` を更新したときと、新しく clone したときは、手順 1 をもう一度実行する。`.agents/plugins/superpowers/` は、Git では追跡しない(`.gitignore`)。

- CLI(`agy`)を使う場合は、`agy plugin install https://github.com/obra/superpowers` でも入れられる(superpowers の README)。

## 注意

- プラグインには、`writing-plans`、`executing-plans`、`subagent-driven-development` も入る。このリポジトリは、計画と実装を spec-kit で行い、これら 3 つを「使わない」と決めている(`AGENTS.md`)。Claude Code と同じく、この方針は指示で守らせる形で、ツールが使えなくするわけではない。
- Antigravity IDE の `brainstorming` のブラウザ補助(`skills/brainstorming/scripts/` の `server.cjs`)は、`localhost` で待ち受けるサーバーで、画面に外部の画像(`primeradiant.com` のロゴ)を読み込む。使うかどうかは、そのときに決める。

## 確かめていないこと

- Antigravity IDE が、`.agents/plugins/superpowers/` のプラグインを読み込むか(コピーするファイルの範囲は、必須の範囲が公式に記載されていないため、除外した分が不足の可能性がある。足りなければ、`scripts/setup-antigravity-plugins.py` の `EXCLUDE` を直す)。
- 導入したときに、`using-superpowers` が会話の最初に自動で読み込まれるか(README の記述は `agy plugin install` の場合)。
- Codex の公式の一覧に、superpowers が出るか(superpowers の README の記述のみ)。
- 実機の結果: Antigravity IDE と Codex アプリの両方で、superpowers が読み込まれ、Codex では `brainstorming` が起動することを、ユーザーが確認した(2026-11-16。`docs/共有環境/共有の一覧.md`)。`using-superpowers` の自動読み込みなどの細かい動作は、聞いていない。
