## 4. 注意

1. **動画本体との照合は、していない**。`sakurai-skill` の記述が、桜井さんの発言どおりかは、確認できていない。
2. **根拠が不明な数値と、強い言い方が多い**。対戦の勝率が約 47〜51% に収まること、「最初の 3 分」、続編の売上は約半分、10 人のチームの実作業は 7 人分、対戦曲は 130〜170BPM などは、出所が書かれていない。「必ず」「絶対」に相当する言い方(ヒットストップは必ず入れる、キーコンフィグは必ず付ける、多数決で決めない、プランBは書かない、など)も多い。これらは、経験則や主張で、検証された事実ではない。
3. **原則どうしが、食い違うところがある**。駆け引きが「面白さの本質」と書く箇所と、「一部」と書く箇所(006 と 026、146)。仕様変更を避けたいことと、柔軟さ(029 と 185)。熱を保つため人に話さないことと、思ったらすぐ言うこと(142 と 060)。相談役は、断定として使わず、条件つきで示す必要がある。
4. **ジャンルと規模に偏る**。対戦アクション(スマブラ)、大作、大規模なチームが前提の例が多い。パズル、物語中心、シミュレーション、モバイル、運営型、個人開発・少人数の原則は、ほぼない。`sakurai-skill` 自身が、読み替えを求めている。
5. **自動字幕に由来する誤りの疑い**がある箇所がある(固有名詞、作品名、専門語)。誤りと断定できたものは、なかった。
6. **範囲**: 精読したのは、`sakurai-skill` の 15 ファイル(約 6.8 万字)。参照ファイルは、動画ごとの要点を並べたもので、ゲーム性・企画・コンセプト・仕様の 4 ファイルで約 88 本分、表現系の 5 ファイルで約 84 本分(エージェントの報告の数)。技術・運営系 5 ファイルの本数と、重複を除いた動画の総数は、数えていない。257 本のうち、どれだけが載っているかは、確認していない。
