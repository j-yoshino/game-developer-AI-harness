# 1. 遊びの核

## 見方の説明

何が面白さの中心かを見る見方。遊びの核を先に決め、それに寄与しないものは削って優先順位をつける。長所と短所を大きく持たせ、調整で平均化しない。気持ちよさを作るときは、反対の要素(落ちる怖さ、遅くなる条件など)を意図的に混ぜる。

## 相談役が投げる問い

- このゲームで、遊ぶ人が一番「気持ちいい」「うれしい」と感じる瞬間はどこか。一言で言うと何か。
- その瞬間を成り立たせている行動は何か。その行動には、どんなリスクや不自由が伴うか。
- 今ある要素のうち、核に寄与しないものはどれか。削る、あるいは後回しにできるのはどれか。
- 一つだけ残すとしたら何か。二番目は何か。優先順位は決まっているか。
- 「〇〇みたいなゲーム」と言うとき、その〇〇にはない魅力は何か。
- 長所を伸ばしたとき、それに見合う短所は残っているか。全部を無難に整えていないか。

## 根拠

### 任天堂の記事(出典つき)

- **記事 052「遊びの核をはっきりさせる」** — https://www.nintendo.co.jp/jobs/keyword/52.html(職種: 理工系(ソフト) / ゲーム開発。強さ: 強)
  - 要約: 新人プログラマーが敵ボスの案を何度も却下され、散らかった案を整理するために「遊びの核をはっきりさせる」という考え方に立ち返った話。何を撃ち抜いたら気持ちよく、撃ち抜いて何が起きたらうれしいかに絞って考え直し、案が通る形に至った。核を問いの形で絞ることが案を決める手順になっている。
- **記事 174「意見を出し合い、より良い形を探る」** — https://www.nintendo.co.jp/jobs/keyword/174.html(職種: 記事中の自己紹介による任天堂側のディレクター。強さ: 強)
  - 要約: 推理を必須にすると苦手な人に遊びにくいと分かり、バトルの軸を直感的な魔法バトルに据え直して推理は味付けに回した話。チームで実際に遊びながら「何が遊びの中心か」「どの瞬間が楽しいか」を話し合って決めている。特長だった要素でも、核でなければ位置づけを下げている。
- **記事 080「ひたすら考え、作っては試して」** — https://www.nintendo.co.jp/jobs/keyword/80.html(職種: 記事に記載なし。強さ: 中)
  - 要約: 最初の試作に新しい体験がなく、運動を徹底的に調べた結果、バトルを多様な運動の「入れ物」にするという捉え方に絞った話。運動を動き方の型の数種類に分類して組み込んだ。核の定め方というより、試作で核を探し当てる過程の例であり、直接の記述は限られる。
- **記事 149「遊びと向き合い、デザインする」** — https://www.nintendo.co.jp/jobs/keyword/149.html(職種: 記事中の自己紹介によるキャラクターデザイナー。強さ: 中)
  - 要約: 敵デザインを、攻略のヒントが見た目で伝わる設計として扱い、実際に動かして遊びの手ごたえに合わせて形を修正した話。遊びの核になる部分を少人数で先に作り、全員で確認して練り直す進め方も述べられている。核の言語化そのものは主題ではない。

### 二次資料の複合結果(出典なし)

- ゲーム性の中心は、リスクを負うとリターンが得られる駆け引きの構造だとされる。リスクとリターンは近い位置に、釣り合った大きさで置くのがよいとされる。(強)
- 気持ちよさには反対の要素が要るとされる。浮遊感は落ちることから、速さは遅くなる条件があることから生まれる、という考え方。(強)
- 調整で強すぎるものを削り弱いものを足し続けると、全部が同じになり平凡になるとされる。長所を伸ばしたら短所も伸ばし、直すなら威力は残して別の軸で調整する、という考え方。個性と均衡は両立できるとされるが、その根拠は一つの対戦作品の数値に依っている。(強)
- 面白さの基本形は、ストレス(敵・障害・謎)を与え、排除や成長や進展で解消させる流れだとされる。(中)
- キャラクターや敵は、一言で特性を言える程度まで尖らせるのがよいとされる。(中)
- 面白さは真似ではなく、分解して理由を考え、独自に再構築して作るとされる。「〇〇みたいなゲーム」で終わらせず、元にない魅力を複数積むべきだという考え方。(中)
- コンセプトは魅力の方向を定める核で、長期開発で面白さが見えなくなっても曲げないとされる。多数決は無難なものが残るので避け、全体像を持つ人が決めるとされる。ディレクター体制のある開発が前提の考え方。(中)
- 遅れや予算超過のときは重い要素を切って進路を補正するとされる。(弱)

## 失敗の兆候

- 依頼や仕様が機能の列挙になっていて、どれが一番大事か優先順位が書かれていない。
- 「面白くなる要素」を足す話ばかりで、削る話が出てこない。
- 「〇〇のようなゲーム」と言うだけで、そのゲーム固有の気持ちよさの説明がない。
- 気持ちよさの説明に、それに伴うリスクや不自由がない(強い、速い、簡単、の方向だけ)。
- 要素ごとに強さを揃えようとして、特徴のない仕様になっている。

## この見方の限界

- 任天堂の記事は、核の決め方を直接述べたものが 052 と 174 の2本で、残りは間接的である。核を決める手順として一般化できる厚さはない。
- 事例は、シューティングやアクション、運動、レースといった遊びが明確なジャンルと、チームで試作を繰り返せる大規模な開発に偏っている。個人制作や、遊びより物語や雰囲気が中心のゲームには、そのまま当てはまらない可能性がある。
- 二次資料のリスクとリターンの考えは、対戦アクションや大作の経験に基づくとされる。パズルや物語中心のゲームでは「核」を別の言葉で捉え直す必要がある。
- 資料の原則どうしの食い違いがある。核を貫いて曲げない考え方と、試作で遊びながら方針を大きく見直した事例(記事 174)は、緊張関係にある。核を決めた後にどこまで見直すかは、資料からは決められない。
- 「核を絞る」ことと、「平均化しない」ことは、強い特徴を持つ分だけ遊ぶ人を選ぶ。見方 2(遊ぶ人を第一に)と衝突する場面がある。
