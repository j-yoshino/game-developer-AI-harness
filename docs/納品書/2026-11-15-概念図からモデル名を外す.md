## 完了の判定ごとの報告

### 1. ユーザーが読む HTML(概念図.html、実装フロー.html)から「お客様モデル」の名前を外す

- 何をしたか: `概念図.html` の題名(`<title>` と `<h1>`)を「概念図」にした。図の説明文(`aria-label`)から名前を除いた。「数字は、モデルの手順の番号」を「概念図の手順の番号」に、表の見出し「モデルの役」を「概念図の役」にした。「責任と手続きのモデル」を「責任と手続きの考え方」にした。`実装フロー.html` の「お客様モデルの概念図(シーケンス図)は、〜にある」を、次項の文に置き換えた。
- 確認した方法: `grep -n "モデル" docs/実装フロー/*.html` が、0 件であること。ブラウザーで概念図を開き、JavaScript で、題名と見出しが「概念図」であること、ページ全体の本文に「モデル」の文字が含まれないこと(`hasModel: false`)、表の見出しが「概念図の役」であることを確認した。2 つの HTML のタグの対応を確認した。
- 確認していないこと: 「役所の手続き」「トヨタの自工程完結」という、モデルの出どころの文を、概念図の冒頭の注記に残している。名前ではないため残したが、これも外したいかは、あなたの判断になる。

### 2. 「ハーネスの要件が概念図に沿って作成された」ことを明記する

- 何をしたか: `概念図.html` の冒頭の注記を、「この概念図について。このハーネスの要件(窓口、確かめる者、依頼票、納品書など)は、この概念図に沿って作られている。」に変えた(「このモデルについて」を置き換え)。`実装フロー.html` の冒頭に、「このハーネスの要件は、概念図(シーケンス図)に沿って作られている: 概念図.html(リンク)」の1行を置いた。
- 確認した方法: ブラウザーで、概念図の冒頭の注記の文面を確認した。実装フローの HTML は、リンク先(`概念図.html`)が同じフォルダーにあることと、本文に「モデル」が 0 件であることを確認した。
- 確認していないこと: 「明記して欲しい」の置き場所を、概念図の冒頭の注記と、実装フローの冒頭の1行の2か所と読んだ。他に書きたい場所(たとえば `AGENTS.md`)があるかは、確認していない。「要件が概念図に沿って作られた」という文が、事実として、どこまで言えるか(概念図は、設計の後で作った図で、設計書の元の文書は削除済み)は、確認していない。
